# Early Gupta comparison image

`India_in_350_CE_Joppen.jpg` is Charles Joppen's *A Historical Atlas of India*
(1907), issued by Justus Perthes and available in the public domain via
[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:India_in_350_CE_Joppen.jpg).
It was inspected as a historical comparison, not traced into the output. The
1907 picture represents a broader area and separately marks protected tribes
and a southern campaign; it does not validate every vertex of the source-375
illustration reused by the atlas.
