# World image batch 02: ten historical objects and manuscript pages

Reviewed 2026-11-11. Ten CC0 Met images map to 13 distinct, previously uncovered entries. Museum web-large delivery images are staged in research/v18/world-batch-02/assets/; verified full-resolution source images remain in originals/. Integrated review shard: dist/data/visual-assets-world-batch-02-v18.json. Source entries are unchanged.

## Source and rights method

Each official object page displays Public Domain and each saved API object marks isPublicDomain=true. The saved Met Open Access policy explicitly releases public-domain artwork images under CC0. Original JPEG bytes were decoded, checked and visually inspected together in contact-sheet.jpg. No image is generated.

## Entry and knowledge review

- No demonstrated atlas factual correction was identified. The museum API labels tunic 308120 as Inca, but its current curatorial text attributes the maker to Chuquibamba: the caption follows that more precise attribution. This is a source-catalogue nuance, not an atlas correction.

- The Kongo page contains a generic paragraph saying fifteenth-century artifacts such as this one, but its explicit date is 16th–17th century with later additions. The shard follows the object date and does not present it as an object from the 1491 conversion.

- The Safavid image depicts a sixth-century Sasanian story in a sixteenth-century painting. It is mapped only to Safavid patronage, not as contemporary evidence for Nushirvan’s reforms.

- Useful missing knowledge topics: Chuquibamba provincial weaving within Inca rule; Asante royal goldsmiths and changing lion/leopard symbolism; Majapahit domestic terracotta production. These are suggestions, not new entries.

## Rejected candidates and retrieval limits

- Met v1 search is retired (2026-10-01); switched to its documented v1.1 paginated replacement.

- Object IDs 318413, 318430 and 39184 returned 404 once; no retries.

- Quipu search returned a twentieth-century necklace: excluded. Modern Samarra casts and objects without public-domain images were excluded.

- Seventh/eighth-century western Cambodian Avalokiteshvara excluded from Angkor-period entries. Egyptian beveled-style panel excluded as direct Samarra evidence; actual Samarra tesserae selected instead.

- Full-resolution originals total approximately 30 MB and are research evidence only. The shard uses separately downloaded and verified museum web-large derivatives to satisfy existing delivery limits.
