# V17 historical image review

Reviewed 9 November 2026 (Vancouver). Thirteen new local images, 1,534,669 bytes in total, bring the candidate catalogue to 29. The existing sixteen item objects and assets are unchanged. Activation follows the V17 content gate.

## Admission and observed checks

Each file and rights page was opened, image metadata was obtained from the Wikimedia Commons imageinfo API or the Metropolitan Museum of Art collection API, and the downloaded bytes were decoded and visually inspected. The atlas saves the supplied image or thumbnail without local visual edits. Every item has bilingual alt text, caption, interpretation, reuse note, source URLs, dimensions, byte count and SHA-256. File-specific restrictions and attribution remain separate from the application MIT license.

- **Ida B. Wells:** the [University of Chicago catalogue](https://photoarchive.lib.uchicago.edu/db.xqy?one=apf1-08637.xml) confirms Cihak and Zima, the Wells Papers, identifier apf1-08637 and 1893/1894. Commons uses circa 1895. Both estimates remain visible; no exact sitting date is invented. Original print damage is retained.
- **Equiano:** the [National Portrait Gallery D8546 record](https://www.npg.org.uk/collections/search/portrait/mw42525/Olaudah-Equiano-Gustavus-Vassa) corroborates Daniel Orme after W. Denton, published by Equiano in 1789. This is the named engraved portrait holding a Bible. It is not a disputed identification of another painted sitter. The file links to the new print-and-abolition story.
- **Su Shi:** the file description attributes the 1743 portrait collection to Shangguan Zhou, while the original upload history identifies a 1921 printed edition. Both dates are distinguished.
- **Li Bai:** Liang Kai’s thirteenth-century painting in the Tokyo National Museum is a later representation of the Tang poet. The selected file retains the uncropped composition supplied by that Commons entry.
- **Rizal:** the Commons file identifies an anonymous photograph from approximately the 1890s. Its previous vertical crop by FMSky is credited; no precise sitting date or travel claim is added.
- **Qin Shi Huang:** the British Library image is a nineteenth-century portrayal. It is not used as evidence of the emperor’s appearance.

Images considered but not admitted include the ambiguous alternative Wells file, a sparse Confucius file record, and the Zhu Xi image because there is no matching subject record in this bounded release. No Whina Cooper image is admitted on an uncertain identification.

## Verification boundary

The draft media schema was checked against existing records and explicitly planned V17 IDs. The release gate must repeat record-link and checksum checks against the complete activated manifest; a planned ID is not proof of a published article.
